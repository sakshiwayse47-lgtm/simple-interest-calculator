# Simple Interest Calculator

This is a simple interest calculator.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Example

Principal = 1000  
Rate = 5%  
Time = 2 years

Simple Interest = (1000 × 5 × 2) / 100 = 100

Therefore, the Simple Interest is 100.
